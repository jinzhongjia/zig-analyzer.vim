*zig_analyzer.txt*  The zig-analyzer language server for Zig

==============================================================================
INTRODUCTION                                              *zig_analyzer*

Registers the zig-analyzer language server with an LSP client and adds
|:ZigAnalyzer| for the server's own requests. Supported clients:

- yegappan/lsp (Vim 9)
- prabirshrestha/vim-lsp

The server is registered with the first one that is loaded. Requires
`zig-analyzer` in PATH, and Zig 0.17.0 or 0.17.1.

==============================================================================
INSTALLATION                                    *zig_analyzer-installation*

The plugin is the `editors/vim` directory of the repository; install it with
one of the LSP clients. With vim-plug:
>vim
    Plug 'yegappan/lsp'
    Plug 'jinzhongjia/zig-analyzer', { 'rtp': 'editors/vim' }
<
Vundle and dein.vim take the same `rtp` option. With Vim packages, clone the
repository under `pack/*/opt/` and link its `editors/vim` directory into
`pack/*/start/` (see README.md in the plugin directory).

==============================================================================
OPTIONS                                              *zig_analyzer-options*

*g:zig_analyzer_cmd*        The server command, a List or a String.
                          Default: `['zig-analyzer']`.

*g:zig_analyzer_settings*   The server settings: the options of
                          `zig-analyzer.default.zon` as a Dictionary
                          (`.build = .{ .args = .{"-Dfoo"} }` is
                          `{'build': {'args': ['-Dfoo']}}`, enum literals are
                          strings). `zig-analyzer.zon` in the project root
                          takes precedence over them. Default: `{}`.

*g:zig_analyzer_enable*     0 to not register the server. Default: 1.

Set them before the LSP client loads, for example in |vimrc|:
>vim
    let g:zig_analyzer_settings = {
          \ 'build': {'args': ['-Dtarget=aarch64-linux']},
          \ 'inlay_hints': {'parameters': v:false},
          \ }
<
The workspace root is the nearest directory containing `build.zig` or `.git`.

==============================================================================
COMMANDS                                             *zig_analyzer-commands*

                                                            *:ZigAnalyzer*
:ZigAnalyzer status          Show the server status (queries, memory).
:ZigAnalyzer fileStatus      Show how the server treats the current file.
:ZigAnalyzer syntaxTree      Show the syntax tree of the current file.
:ZigAnalyzer moduleGraph     Show the module graph of the projects.
:ZigAnalyzer reloadWorkspace Rerun `build.zig` and reload the projects.
:ZigAnalyzer restart         Restart the server.
